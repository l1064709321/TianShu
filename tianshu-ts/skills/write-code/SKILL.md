# 写代码技能

使用本技能来完成编程类任务:审查代码、编写新代码、修复 bug、重构。

## 流程

1. 先用 search_files / read_file 理解代码库结构与现有约定
2. 编写或修改代码,遵循项目现有风格与框架选择(不随意引入新依赖)
3. 不要添加多余注释,除非用户要求
4. 完成后运行测试或检查命令验证
5. 汇总改动与验证结果

## 注意事项

- 不提交 git,除非用户明确要求
- 高危改动(删除、重写)需先征得同意
